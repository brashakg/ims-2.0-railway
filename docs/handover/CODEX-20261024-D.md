## Changes

1. Brand create/update uses one normalization rule: while `never_sell_online` is true, `sync_to_shopify_default` is false. Partial updates consult the existing block, so omitting that field cannot bypass the rule. Existing SUPERADMIN permissions and take-down behavior remain. The form clears and disables the sync checkbox with an explanation; clearing the block leaves sync off until explicitly selected. Older contradictory brands are normalized in the form and on their next save; no production backfill was run.
2. Grouped catalogue rows carry each member's own creation/editor metadata, resolved through the existing name resolver and last-edit expression. Expanded rows use the same display formatter as the main row. Nested attribution is stripped for roles that cannot see it. A later non-edit `updated_at` does not overwrite the displayed edit date when `edited_at` exists.
3. Display labels say Sunglasses, including the remaining estimate option and promotion example text. `SG`, `SMTSG`, `SUNGLASS` and all payload/category codes remain unchanged. Existing UI selectors follow the new displayed name; unrelated product fixtures remain unchanged.
4. The current baseline did not contain a literal Product images 0/0 counter. The upload section now says `Photos: N added (website needs at least 1 usable photo)`. The count is the form's image list length. The existing push gate requires a usable HTTP(S) photo URL; two or more photos and the five suggested angles are guidance, not mandatory counts. Upload, reorder, remove, background editing and sibling-copy controls are retained.
