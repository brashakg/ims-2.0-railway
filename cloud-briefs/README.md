# Cloud briefs

Task briefs for cloud sessions started by hand on claude.ai/code (they run on the cloud-session credit).
Each file is self-contained. A session is started with one line, for example:

    Follow the brief cloud-briefs/po-edit-cancel-send.md on branch ops/cloud-briefs of this repo: run
    `git fetch origin ops/cloud-briefs && git show origin/ops/cloud-briefs:cloud-briefs/po-edit-cancel-send.md` and do exactly what it says.

This branch is never merged into main.
